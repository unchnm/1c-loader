# 1C: Загрузка изменений

Боковая панель VS Code и Cursor для частичной загрузки изменённых XML/BSL-файлов в базу 1С.

На панели действий кнопка **1C: Загрузка**. Форма остаётся в боковой панели: путь проекта, база из `ibases.v8i`, список git-изменений и кнопка загрузки. Список баз обновляется при открытии, изменения — по значку обновления. После успешной загрузки открывается конфигуратор, конфигурация базы данных не обновляется.

Загрузка вызывает `1cv8.exe DESIGNER /LoadConfigFromFiles` со списком файлов `-listFile`. Файл `.1c-devbase.bat` в репозитории не создаётся и не изменяется.

Нужны Windows, Git и установленная платформа 1С.

```
npm install
npm test
npm run package
```

Файл `onec-loader-0.2.0.vsix` ставится командой **Extensions: Install from VSIX**.
