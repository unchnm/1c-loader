# 1C: Загрузка изменений

Боковая панель VS Code и Cursor для частичной загрузки XML/BSL-файлов в базу 1С. Версия расширения — `0.3.0`.

После установки представление **1C: Loader** доступно в боковой панели VS Code и Cursor. В нём можно выбрать каталог проекта, информационную базу из `ibases.v8i`, просмотреть список Git-изменений и запустить загрузку. Список баз обновляется при открытии представления, список изменений — по команде обновления.

В меню дополнительных параметров откройте раздел **Список файлов**. В нём находится пункт **Только незакоммиченные**, включённый по умолчанию и отмеченный галочкой. Если снять галочку, список расширяется и включает XML/BSL-файлы из коммитов текущей ветки, отсутствующих в остальных локальных и remote-tracking ветках, вместе с незакоммиченными изменениями. Каждый путь отображается один раз; удалённые файлы исключаются.

После успешной загрузки открывается конфигуратор, конфигурация базы данных не обновляется.

Загрузка вызывает `1cv8.exe DESIGNER /LoadConfigFromFiles` со списком файлов `-listFile`. Файл `.1c-devbase.bat` в репозитории не создаётся и не изменяется.

Нужны Windows, Git и установленная платформа 1С.

```
npm install
npm test
npm run package
```

Файл `onec-loader-0.3.0.vsix` ставится командой **Extensions: Install from VSIX**. Готовые файлы доступны на странице [релизов](https://github.com/unchnm/1c-loader/releases).
