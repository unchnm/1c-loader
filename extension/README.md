# 1C: Загрузка изменений

Боковая панель VS Code и Cursor для частичной загрузки XML/BSL-файлов в базу 1С. Версия расширения — `0.3.0`.

На панели действий кнопка **1C: Загрузка**. Форма остаётся в боковой панели: путь проекта, база из `ibases.v8i`, список git-изменений и кнопка загрузки. Список баз обновляется при открытии, изменения — по значку обновления.

Рядом с обновлением находится кнопка с тремя точками. В её настройках доступен пункт **Показывать только незакоммиченные изменения**, включённый по умолчанию. Включённый пункт оставляет текущую логику и показывает только изменения рабочей копии. При отключении расширение добавляет файлы из коммитов текущей ветки после точки расхождения с `main`/`master` и объединяет их с незакоммиченными изменениями без дублей. В список попадают XML/BSL-файлы внутри каталога конфигурации, удаления исключаются.

После успешной загрузки открывается конфигуратор, конфигурация базы данных не обновляется.

Загрузка вызывает `1cv8.exe DESIGNER /LoadConfigFromFiles` со списком файлов `-listFile`. Файл `.1c-devbase.bat` в репозитории не создаётся и не изменяется.

Нужны Windows, Git и установленная платформа 1С.

```
npm install
npm test
npm run package
```

Файл `onec-loader-0.3.0.vsix` ставится командой **Extensions: Install from VSIX**. Готовые файлы доступны на странице [релизов](https://github.com/unchnm/1c-loader/releases).
